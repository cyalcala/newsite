# Buyer-focused copy revision — 2026-09-13

## Purpose and audience

Rewrite the existing website for a visitor deciding whether to invest time or money in Cyrus's services. Primary audience: prospective website/content/AI buyers. Secondary audience: employers and people evaluating the working products. This is service positioning, not a fundraising offer or a promise of investment returns.

The user requested a benefits-led, readable full-content pass and removal of repetitive independent positioning. Copywriting and copy-editing skills supported the work; the existing Design Loop direction and one-form contact strategy remain in place.

## Main changes

- Homepage: Websites that earn trust. The introduction explains customer understanding and the next step, then identifies Cyrus as the designer/developer.
- Services: deliverables now explain their use to the buyer. Starter pricing, scope, ongoing costs and handover remain explicit.
- Work and case studies: front-load the user problem and working functionality. Explain what a prospective buyer can inspect. Technical implementation stays in disclosures.
- About: connect operations and technical-writing experience to customer clarity, usability and handover.
- Hire Me: lead with how the skills help a team; preserve employers, dates, résumé and credentials.
- Video: help visitors compare formats for their message. Preserve concept labels and synthetic-endorsement disclosure.
- Footer: explain that the short form begins the conversation and that Cyrus replies using the details supplied.
- Metadata: descriptions now summarize visitor value on every substantive page.

All inquiry actions retain the shared Let's talk label and published Google Form. No new budget fields, guarantees, quantified results, customer logos, financing claims or adoption claims were added. Google AI credentials and Grok Bots remain. No CSS, JavaScript or media changes were needed.

## Editorial review

The same author performed these review passes; they are not independent customer research or conversion-test results.

| Lens | Revision/check |
|---|---|
| Buyer | Replace self-description with useful outcomes, scope, inspectable work and an understandable next step. |
| UX writer | Shorten paragraphs and technical explanations, use descriptive headings and verify wrapping on actual rendered pages. |
| Skeptical evaluator | Keep facts within the existing evidence record. Preserve product/data limitations and distinguish concepts from client results. |
| Editor | Review clarity, consistent tone, benefits, evidence, specificity, emotional restraint and contact friction. Remove repeated independent language and vague maker slogans. |

Headline alternatives considered: Websites that earn trust (selected: customer confidence, short enough for the existing cover); Make your offer easy to understand (used for the website case); Help customers choose you (more outcome-forward, less explicit about the service). The shared Let's talk action remains by the user's prior decision; nearby text explains what happens next.
