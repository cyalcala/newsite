Built from a writer's problem.

Technical writing asks for more than fluent sentences. A useful answer needs source context, accurate terminology and diagrams a reader can follow. My experience writing knowledge and process documentation shaped the problem I wanted this tool to address.

A workspace, with the writer in control.

The interface brings document questions, draft reviews, diagrams and exports into one working session. Writers choose what to provide and which checks to run. Source references help them inspect the result rather than accept an answer on appearance alone.

I built the application and its document-context workflow, including the states that matter when a file only partly indexes, a source is unavailable or a diagram needs repair.

A practical writing loop.

01 / CONTEXT

Bring the material.

Add a document or ask about a technical task.

02 / WORK

Draft and examine.

Use questions, review tools and diagrams to develop the explanation.

03 / REVIEW

Check, then export.

Inspect sources and output. Keep the parts that stand up to review.

Where my disciplines meet.

This project connects technical writing, knowledge management, interface design and AI development. It shows how understanding an existing job can lead to a more specific software tool.

AI output still needs human review. Document context is held in the active session; export work before leaving. Requested AI and rendering features may use configured external providers. This is a working independent project, not a claim of enterprise adoption.
Under the hood: document context and outputs

Astro and Svelte provide the interface; Cloudflare hosts the application. The document pipeline validates and extracts text, splits it into searchable passages and carries filename/line references into retrieval. Explicit review tools and diagram rendering support the writing workflow.

Provider fallback and error states help the application explain failures. Active-session storage is not a promise that all processing happens on the device. Source and operational documentation describe the current boundaries.
